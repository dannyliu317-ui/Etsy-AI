# Etsy AI — Windows Quick Start

## Recommended

1. Install Python 3.11.
2. Download this repository branch:
   `feature/relief-pendant-v1`
3. Extract the project folder.
4. Double-click:

`start_etsy_ai_windows.bat`

The launcher will:

- create a local `.venv`
- install `requirements.txt`
- install OpenCV for V7–V10 portrait detection
- start Streamlit
- open the app at `http://localhost:8501`

## First V10 test

Open the section:

**3. V9.1 Jewelry Memorial Portrait Coin**

Recommended first settings:

- Pendant Shape: Circle
- Size: 30 mm
- Manufacturing Process: Jewelry Casting
- Metal / Relief Style: Sterling Silver
- Production Process: Jewelry Casting
- Relief Profile: Balanced Portrait
- Keep the remaining V10 values at their defaults

Then upload a customer portrait and generate the STL.

## Important

The V5/V6/V7/V8/V9/V9.1/V10 production reports are design-for-manufacture aids. They do not replace the actual jewelry manufacturer's tolerance review.

For the first real order, make one physical sample before using the same parameters for a larger batch.
